# SoundLab

**SoundLab** — учебное приложение для лабораторной работы по исследованию
частотных и слуховых параметров аудиосигналов. Программа позволяет формировать
тональные сигналы (синусоидальные, модулированные по амплитуде / частоте / фазе),
накладывать шум и помехи, управлять параметрами воспроизведения (громкость,
азимут, расстояние, левый/правый канал) и просматривать сигнал со спектром.

Приложение предназначено для студентов и используется в лабораторных работах по
обработке и анализу сигналов.

## Возможности

- Формирование тонального сигнала с заданной частотой и громкостью.
- Методом половинного деления оценка частотного и динамического диапазона слуха.
- Модуляция сигнала: **AM** (амплитудная), **FM** (частотная), **PM** (фазовая).
- Наложение шума и гармонических помех с регулировкой отношений сигнал/шум и
  сигнал/помеха.
- Управление пространственными параметрами звука: азимут, расстояние, вращение,
  выбор канала (левый/правый/стерео).
- Отображение сигнала и его спектра (окно FFT на базе Qwt).
- Сохранение настроек между запусками (QSettings).
- Современный интерфейс: тема оформления (QSS), панель инструментов
  («Сброс параметров», «О программе»), подсказки к элементам управления.

## Технологии

- **C++11** и **Qt 5** (Widgets)
- **Qwt** — графики сигнала и спектра
- **OpenAL** — вывод звука

## Требования

Для сборки с помощью CMake необходимы:

- CMake ≥ 3.15
- Компилятор MSVC (64-бит) с поддержкой C++11
- Qt 5 (модули Widgets, Gui, Core, Svg)
- Qwt (заголовки и библиотека `qwt.lib`)
- OpenAL (заголовки и библиотека `OpenAL32.lib`, например OpenAL Soft)

## Сборка (Windows, CMake)

Пути к зависимости по умолчанию можно передать через переменные CMake
`CMAKE_PREFIX_PATH` (для Qt), `QWT_DIR` и `OPENALDIR`.

```bat
:: Конфигурация проекта
cmake -S . -B build -G "Visual Studio 14 2015 Win64"

:: Сборка
cmake --build build --config Release
```

Исполняемый файл будет создан в `build\Release\Soundlab.exe`.

### Развёртывание (запуск без Qt SDK)

После сборки скопируйте в каталог с `Soundlab.exe` библиотеки Qt, Qwt и OpenAL.
Для Qt используется утилита `windeployqt`:

```bat
C:\Qt\5.13.0\msvc2015_64\bin\windeployqt.exe --release build\Release\Soundlab.exe
copy /Y C:\Qwt-6.1.5\lib\qwt.dll build\Release\
:: qwt.dll depends on Qt5OpenGL, which windeployqt does not resolve via the exe alone
copy /Y C:\Qt\5.13.0\msvc2015_64\bin\Qt5OpenGL.dll build\Release\
```
